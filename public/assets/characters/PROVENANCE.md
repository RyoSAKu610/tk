# Character artwork provenance

The twenty encyclopedia sheets in this directory were supplied by the project owner in the Codex task on 2026-08-02 and were explicitly authorized for use in ResearchPhantom Studio. The public WebP sheets are resized derivatives; the seven guide images are crops from the named source sheets.

`manifest.json` records the original file name and SHA-256 for every 10-character sheet so that later replacements can be audited without publishing a local filesystem path. These images are character-led educational illustrations, not portraits authenticated by the historical figures and not depictions of the paper authors.

This record documents project provenance; it does not grant broader third-party redistribution rights. Before changing the publication scope, confirm the project owner's rights policy. Generated scene videos must additionally pass `npm run motion:import -- ... --rights-confirmed`, and their own source hash/provider record is stored in `public/assets/motion/manifest.json`.
